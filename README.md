# Lumora Wallpaper Engine

A modern, open-source wallpaper engine designed for Linux.

Lumora Wallpaper Engine aims to bring beautiful animated and dynamic wallpapers to the Linux desktop while remaining lightweight, customizable, and open source.

> ⚠️ This project is currently in active development. Features and functionality may change as development progresses.

---

## About

Lumora Wallpaper Engine is being developed as part of the Lumora ecosystem.

The goal is to create a modern wallpaper engine that allows Linux users to use dynamic and animated wallpapers without relying on proprietary software.

The project focuses on:

- Animated wallpapers
- Video wallpapers
- Performance and resource efficiency
- Linux desktop compatibility
- Customization
- Open-source development

---

## Features

Planned features include:

- 🖼️ Animated wallpapers
- 🎥 Video wallpaper support
- ⚡ Lightweight performance
- 🎨 Wallpaper customization
- 🖥️ Multi-monitor support
- 🔧 Desktop environment integration
- 🌐 Cross-distribution Linux support

More features will be added during development.
